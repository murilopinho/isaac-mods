# Isaac Mods

Small Lua mods for **The Binding of Isaac: Repentance**, all published on the Steam Workshop.
No REPENTOGON needed. Mod Config Menu is optional in all of them.

| Mod | What it does | Workshop |
|---|---|---|
| [No More Crash Builds](no-more-crash-builds/) | Keeps broken builds (Haemolacria + Parasite, Dr. Fetus + Scatter Bombs...) from freezing or crashing the game, without nerfing them. Skips pure visual effects under load and folds split-tear damage into the parent tear. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3808770484) |
| [Pickup Merge](pickup-merge/) | Merges piles of coins, keys, bombs and hearts into their bigger versions. Same value, fewer entities, better FPS. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3808771551) |
| [Treasure Offering](treasure-offering/) | Leave a trinket in the Treasure Room. Once the floor's boss is dead, it turns into a Cracked Key. One per floor. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3810030569) |
| [Blood Loan](blood-loan/) | The first Sacrifice Room of the run lends you 3.5 hearts. What you don't give back, it takes. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3811633004) |
| [Golden Swap](golden-swap/) | A second Golden Key becomes a Golden Bomb and vice versa. Already have both? 10 keys or 14 bombs. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3811973480) |
| [Free Flesh Door](Keep%20the%20kinife/) | Beat Mom and get the Knife Pieces you're missing, so the flesh door opens. Keeping the knife is optional. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3811982185) |
| [No Curse of the Blind](no-curse-of-the-blind/) | No more "?" pedestals. Floors with no curse get a 15% chance to roll another one. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3811316323) |
| [Shop Gulp](shop-gulp/) | Every 2nd new shop leaves a Gulp! pill on the floor. Up to 2 per run. | [link](https://steamcommunity.com/sharedfiles/filedetails/?id=3811313260) |

## Install

Subscribe on the Workshop (easiest), or copy a mod folder into
`The Binding of Isaac Rebirth/mods/`.

Each folder's `metadata.xml` has the full description and the current version.
